備忘録
Pythonの実行環境を作り、composited_image.pyがあるフォルダーに、背景となる画像（名前は"back.png"）を置き、コマンドでPythonファイルを実行します。
追加する画像の位置テンプレートを作成すると、フォルダーに、"template.json"ファイルが自動作成されます。
背景画像の変更や位置テンプレートを更新する場合は、アプリのフォルダーから移動してください。新しい画像は"back.png"にしてください。

背景画像の大きさは、以下に固定しています。使用する画像に合わせて修正してください。
```
CANVAS_W, CANVAS_H = 1200, 800
```

追加画像の大きさは、以下に固定しています。使用する画像に合わせて修正してください。
```
self.thumb_size = (90, 150)
```

Pythonのライブラリは、以下を使用しました。
```
Package Version
------- -------
pillow  13.0.0
pip     26.2.2
```
